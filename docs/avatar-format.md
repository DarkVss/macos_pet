# Формат спрайтового аватара, версия 1

Аватар — папка с `manifest.json` и отдельным PNG-листом для каждого состояния.
Для передачи папку можно упаковать в ZIP. В корне архива должны находиться
`manifest.json` и папки состояний, без дополнительной внешней папки.
Встроенный пример находится в `Pet/Resources/Kinoko.bundle`.
Расширение `.bundle` используется для копирования ресурсов Xcode;
загрузчик принимает обычную папку и не требует сборки атласа в Xcode.

```text
manifest.json
waiting/sprites.png
rest/sprites.png
running-right/sprites.png
running-left/sprites.png
greeting/sprites.png
gaze/sprites.png          # необязательно
```

Обязательные состояния:

| Ключ | Название |
|---|---|
| `waiting` | Спокойное ожидание: неподвижное тело и моргание, без покачивания и жестов |
| `rest` | Отдых |
| `running-right` | Бег вправо |
| `running-left` | Бег влево |
| `greeting` | Приветствие |

`manifest.json` задаёт имя, общий размер кадра и параметры каждого листа:

```json
{
  "schemaVersion": 1,
  "name": "Мой питомец",
  "frameWidth": 192,
  "frameHeight": 208,
  "animations": {
    "waiting": {
      "file": "waiting/sprites.png",
      "columns": 6,
      "frameCount": 30,
      "fps": 30,
      "pause": 0.6
    }
  }
}
```

В примере выше показано одно состояние; в готовом пакете нужны все пять.
Полный рабочий пример — `Pet/Resources/Kinoko.bundle/manifest.json`.

- PNG должен иметь прозрачный фон. Кадры идут слева направо, затем сверху вниз.
- Все кадры имеют одинаковые размеры; сохраняйте масштаб и опорную точку тела.
- Ширина листа равна `columns × frameWidth`, высота —
  `ceil(frameCount / columns) × frameHeight`. Лишние ячейки последнего ряда
  оставляйте прозрачными.
- Для 30 кадров размером 192×208 и шести колонок лист имеет размер 1152×1040.
- Можно задать своё количество кадров и FPS; 30 кадров не являются ограничением
  формата. Отдых в текущем аватаре — один кадр с закрытыми глазами.
- `pause` — пауза в секундах после цикла; во время паузы показан первый кадр.
- Пути к PNG задаются относительно корня пакета; файлы вне пакета не допускаются.
- Загрузчик проверяет версию, наличие состояний, параметры и размеры листов.
  Поддерживается 1–600 кадров на состояние, 1–60 FPS, пауза 0–60 секунд,
  размер кадра до 1024×1024. Лист — до 8192 по стороне и 16 777 216 пикселей.

Необязательное поле `gaze` имеет те же поля, что и состояние. Оно должно
содержать 16 кадров: от взгляда вверх (0°) по часовой стрелке, шаг 22,5°.
Если `gaze` отсутствует, меню направлений взгляда скрывается.

Сейчас приложение читает встроенный пакет. Диалог выбора ZIP, распаковка,
установка в пользовательскую библиотеку и переключение аватаров ещё не
реализованы. Будущий импорт должен распаковать архив в отдельную папку,
проверить его через `SpriteAvatar(rootURL:)` и только затем установить.
